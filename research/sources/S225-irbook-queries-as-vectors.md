## Passages
### P1 query vector
> we can also view a query as a vector.
### P2 top scoring
> The resulting scores can then be used to select the top-scoring documents for a query.
### P3 not all terms
> A document may have a high cosine score for a query even if it does not contain all query terms.
### P4 cost
> a single similarity computation can entail a dot product in tens of thousands of dimensions
