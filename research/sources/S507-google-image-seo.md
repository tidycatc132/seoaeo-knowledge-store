Summary: Google guidance on images: alt text, nearby text, HTML img elements, formats, image sitemaps.
## Passages
### P1 alt
> The most important attribute when it comes to providing more metadata for an image is the alt text.
### P2 nearby text
> Wherever possible, make sure images are placed near relevant text.
### P3 formats
> BMP, GIF, JPEG, PNG, WebP, SVG, and AVIF.
### P4 css
> Google doesn't index CSS images.
### P5 filenames
> When possible, use filenames that are short, but descriptive.
### P6 standard img elements
> Using standard HTML image elements helps crawlers find and process images.
### P7 img src
> Google can find images in `src` attribute of `<img>` element
