Summary: Google explains that regular snippets are made automatically from page content, vary by search, and may use the meta description when it's more accurate.

## Passages

### P1 automatic
> Snippets are automatically created from page content.

### P2 query based
> Snippets are designed to emphasize and preview the page content that best relates to a user's specific search.

### P3 differ
> This means that Google Search might show different snippets for different searches.

### P4 meta description
> if it might give users a more accurate description of the page than content taken directly from the page.

### P5 describe page
> Wherever possible, create descriptions that accurately describe the specific page.
