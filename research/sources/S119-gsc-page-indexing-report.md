Summary: Defines Search Console index statuses such as crawled-not-indexed, discovered-not-indexed and duplicate-canonical states.
Note: quotes were returned by WebFetch extraction; fragments kept short.
## Passages
### P1 crawled
> The page was crawled by Google but not indexed.
### P2 discovered
> The page was found by Google, but not crawled yet.
### P3 dup-no-canon
> This page is a duplicate of another page, although it doesn't indicate a preferred canonical page.
### P4 dup-diff
> This page is marked as canonical for a set of pages, but Google thinks another URL makes a better canonical.
### P5 blocked
> This page was blocked by your site's robots.txt file.
### P6 indexed-blocked
> The page was indexed despite being blocked by your website's robots.txt file.
### P7 alternate with canonical
> This page correctly points to the canonical page, which is indexed, so there is nothing you need to do.
