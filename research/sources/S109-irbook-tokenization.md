Summary: Defines token, type and term and shows tokenization is not trivial (apostrophes, hyphens).
Note: quotes were returned by WebFetch extraction; fragments kept short.
## Passages
### P1 token
> A token is an instance of a sequence of characters in some particular document
### P2 type
> A type is the class of all tokens containing the same character sequence.
### P3 term
> A term is a (perhaps normalized) type that is included in the IR system's dictionary.
### P4 tokenization
> tokenization is the task of chopping it up into pieces, called tokens
### P5 hyphens
> Handling hyphens automatically can thus be complex
