Summary: Markup lets you tell Google about hours and departments; the Required properties table lists address and name (P7-P9). Page says nothing about ranking or NAP consistency.
## Passages
### P1 purpose
> you can tell Google about business hours, different departments within a business
### P2 required
> You must include the required properties for your content to be eligible for display as a rich result.
### P3 no guarantee
> Google does not guarantee that features that consume structured data will show up in search results.
### P4 phone
> Be sure to include the country code and area code in the phone number.
### P5 address description
> The physical location of the business. Include as many properties as possible.
### P6 name description
> The name of the business.
### P7 table header
> Required properties
### P8 required name row
> `name` `Text`<br>The name of the business.
### P9 required address row
> `address` `PostalAddress`<br>The physical location of the business.
