Summary: Google's illustrated guide to the common parts of a results page: text, image and video results among others. Notes how elements look changes over time and by device.

## Passages

### P1 what
> The Visual Elements gallery is an illustrated guide to the most common UI elements of Google web search

### P2 building blocks
> Visual elements are the building blocks of the Google Search results page that a user can perceive or interact with.

### P3 different types
> The Google Search results page contains a set of different types of search result visual elements

### P4 image result
> An image result is a result that's based on an image that's embedded on a web page.

### P5 video result
> A video result is a result that's based on a video that's embedded on a web page.

### P6 text result
> A result in Google Search that's based on the textual content of the page.

### P7 change over time
> How the visual elements look can change over time

### P8 device
> a given result can be displayed differently depending on whether you're using a desktop computer or a phone
