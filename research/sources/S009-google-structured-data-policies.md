Summary: Google policy: markup must truthfully represent visible page content; misleading markup can trigger a manual action that removes rich result eligibility.
## Passages
### P1 true representation
> Your structured data must be a true representation of the page content.
### P2 visible content
> Don't mark up content that is not visible to readers of the page.
### P3 no deception
> Don't use structured data to deceive or mislead users.
### P4 manual action
> If your page contains a structured data issue, it can result in a manual action.
### P5 consequence
> A structured data manual action means that a page loses eligibility for appearance as a rich result;
