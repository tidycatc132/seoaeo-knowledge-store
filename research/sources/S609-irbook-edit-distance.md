Summary: Textbook definition of edit distance and the three edit operations, with the cat/dog example. Describes a method, not any engine's behaviour.
## Passages
### P1 definition
> Given two character strings s1 and s2, the edit distance between them is the minimum number of edit operations required to transform s1 into s2.
### P2 operations
> (i) insert a character into a string; (ii) delete a character from a string and (iii) replace a character of a string by another character
### P3 example
> For example, the edit distance between cat and dog is 3.
