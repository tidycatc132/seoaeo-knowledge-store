Summary: Textbook section on query expansion: users or thesauri add synonyms and related words to the query. Covers query-log mining of other users' reformulations. Expansion generally raises recall.
## Passages
### P1 expansion vs feedback
> users give additional input on query words or phrases, possibly suggesting additional query terms.
### P2 thesaurus
> the query can be automatically expanded with synonyms and related words
### P3 query logs
> Here, we exploit the manual query reformulations of other users to make suggestions to a new user.
### P4 recall
> Use of query expansion generally increases recall and is widely used in many science and engineering fields.
### P5 no user input
> Thesaurus-based query expansion has the advantage of not requiring any user input.
### P6 weighting
> for instance, one might weight added terms less than original query terms.
