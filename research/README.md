# Research archive

Plain markdown, append-only. Plan: https://claude.ai/artifact/5fnqc8GKin3hptCb5N5qGe

- `sources/S###-slug.md`: one note per source (header, 3-line summary, quoted passages with labels).
- `topics/T##-slug.md`: one notes file per topic (findings with source ids, conflicts, dead ends, what was cut).
- `log.md`: one line per agent run.
- `../bank/items/T##-slug.json`: the question bank, one file per topic.

Source grades: A primary (platform docs, original papers, testimony, standards), B authoritative secondary (textbooks, surveys, engineer posts), C industry study with published method, D opinion (not used for answers).
